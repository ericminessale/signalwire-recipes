# Browser Call Widget

> A call button for your own site: short-lived tokens that can only reach your support address, and nothing else.

## What this demonstrates

Two recipes: a browser leg into your call flow, and a token that cannot dial anywhere except where you allowed.

## How it works

Each composed recipe is documented on its own page; this build shows them running
in the same flow, with the state that has to survive between them.

## Limitations

A full application rather than a snippet. Read the composed recipes first if you
only need one piece.

## What to change first

The routing rules, then the copy.
